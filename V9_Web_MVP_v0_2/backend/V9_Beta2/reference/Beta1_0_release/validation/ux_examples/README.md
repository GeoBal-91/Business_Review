# Beta UX examples

These nine synthetic decks are illustrative regression fixtures, with normal and Beta audit exports beside each deck. They are generated from `tests/beta_fixtures.py` using `tests/build_beta_examples.py`.

The real, uploaded-input sample is at the package root. Every slide from all ten decks was rendered and checked. The companion `V9_Beta1_0_UX_Examples.zip` contains every rendered PNG, including the 43-slide real sample. See the root regression report and `validation/render_checks/` for evidence.

`V9_Beta1_0_Thirty_Stores.pptx` is the large synthetic example: 59 slides, three Overview pages and every individual Diagnostic. Store names in the Overview link to their Diagnostic slide.
