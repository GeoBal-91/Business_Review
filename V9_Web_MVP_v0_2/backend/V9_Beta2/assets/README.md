# Visual Assets

Reusable Glovo visual assets extracted from the supplied `Icons and pictures.pptx` library for this project.

Included:
- `glovo_logo.png`
- five main vertical icons
- six arrow variants
- six blob variants
- two phone mockups

The PPT code treats these as optional assets. Missing assets do not stop deck generation. Partner logos remain external as `Partner_Logo.png`.
